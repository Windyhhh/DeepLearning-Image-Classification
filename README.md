**DeepLearning-Image-Classification** walks from theory to practice for image classification with **CNN and ResNet**, including transfer learning, custom-data input, interpolation and an interactive query interface.

> [!NOTE]
> 中文项目：深度学习图像分类——从理论到实践，CNN/ResNet、迁移学习、自定义输入、交互查询。

---

## Quickstart

```bash
git clone https://github.com/Windyhhh/DeepLearning-Image-Classification.git
cd DeepLearning-Image-Classification

# Interactive query demo
python src/interactive_query.py

# Custom input example
python examples/demo_custom_input.py

# Visualization example
python examples/demo_visualization.py
```

See `docs/START_HERE.md` and `docs/QUICK_START.md` for full setup.

---

## Features

- **CNN / ResNet** — classification models with transfer learning.
- **Custom input** — bring your own images / datasets.
- **Interactive query** — classify on the fly with `interactive_query.py`.
