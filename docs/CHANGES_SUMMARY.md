# X-Y 范围查询功能更新总结

## 问题描述
原项目在输入 x 和 y 条件后，没有对 z 和 t 进行过滤，无法仅显示对应的 z 和 t 值。

## 解决方案
添加了 **X-Y 范围查询功能**，允许用户根据 x 和 y 的范围来过滤并显示对应的 z 和 t 值。

## 修改内容

### 1. interpolation.py
**新增方法：`query_by_xy_range()`**
- 功能：根据 x 和 y 的范围查询对应的 z 和 t 值
- 参数：
  - `x_min`: x 的最小值
  - `x_max`: x 的最大值
  - `y_min`: y 的最小值
  - `y_max`: y 的最大值
- 返回值：满足条件的点列表，每个点包含 x, y, z, t 值

### 2. interactive_query.py
**新增函数：`xy_range_query()`**
- 交互式 X-Y 范围查询函数
- 提示用户输入 x 和 y 的范围
- 显示查询结果和统计信息

**菜单更新**
- 原菜单选项重新编号
- 新增选项 4：X-Y 范围查询 ⭐
- 原选项 7（输入自定义数据）改为选项 8

**批量查询增强**
- 添加 X-Y 范围过滤选项
- 用户可选择按 X-Y 范围过滤或输入具体点坐标
- 支持显示前 100 个结果

## 使用示例

### 交互式查询
```
选择菜单选项 4：X-Y 范围查询
输入 X 最小值: 2.0
输入 X 最大值: 4.0
输入 Y 最小值: 3.0
输入 Y 最大值: 5.0
```

### 批量查询
```
选择菜单选项 7：批量查询
是否按 X-Y 范围过滤？(y/n): y
输入 X 最小值: 2.0
输入 X 最大值: 4.0
输入 Y 最小值: 3.0
输入 Y 最大值: 5.0
```
