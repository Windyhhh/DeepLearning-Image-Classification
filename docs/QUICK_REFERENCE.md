# 快速参考卡 - 自定义数据输入

## 🚀 30 秒快速开始

```bash
# 1. 启动交互式工具
python interactive_query.py

# 2. 选择选项 7
请选择操作 (0-7): 7

# 3. 输入数据点数
输入数据点数: 3

# 4. 输入数据（格式：x y z t）
点 1: 0 0 1 10
点 2: 1 1 2 20
点 3: 2 2 3 30

# 5. 完成！开始查询
```

## 📋 数据输入格式

```
x y z t
```

| 参数 | 说明 | 示例 |
|------|------|------|
| x | 第一个坐标 | 0, 1.5, -2 |
| y | 第二个坐标 | 0, 1.5, -2 |
| z | 第一个值 | 1, 10.5, 100 |
| t | 第二个值 | 10, 20.5, 200 |

## ✅ 数据要求

- **最少**：3 个数据点
- **推荐**：10+ 个数据点
- **格式**：4 个数字，用空格分隔
- **类型**：整数或小数都可以

## 🎯 菜单选项

| 选项 | 功能 | 说明 |
|------|------|------|
| 1 | 显示数据范围 | 查看 X, Y, Z, T 的范围 |
| 2 | 单点查询 | 查询特定 x, y 的 z, t |
| 3 | 范围查询 | 查询满足条件的所有点 ⭐ |
| 4 | 显示三维图形 | 可视化数据 |
| 5 | 显示热力图 | 查看分布 |
| 6 | 批量查询 | 查询多个点 |
| 7 | 输入自己的数据 | **新功能** ⭐ |
| 0 | 退出 | 退出程序 |

## 📝 常见错误和解决方案

| 错误 | 原因 | 解决 |
|------|------|------|
| 至少需要 3 个数据点 | 数据点太少 | 输入至少 3 个点 |
| 需要输入 4 个值 | 值的个数不对 | 每行输入 x y z t |
| 请输入有效的数字 | 输入了非数字 | 输入数字而不是字母 |
| 输入不能为空 | 没有输入数据 | 输入有效的数据 |

## 📞 常见问题

**Q: 如何重新输入数据？**
A: 选择选项 7，输入新的数据即可。

**Q: 数据点数有上限吗？**
A: 没有硬性上限，但太多数据点可能会占用更多内存。

**Q: 可以输入负数吗？**
A: 可以，支持任何浮点数。

**Q: 如何返回示例数据？**
A: 重新启动程序。
