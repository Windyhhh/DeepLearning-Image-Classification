================================================================================
                              主要类和方法
================================================================================

Interpolator3D 类：

初始化：
  Interpolator3D(x_data, y_data, z_data, t_data, grid_spacing=0.01)

核心方法：
  • query(x, y) → Dict | None
    单点查询，返回 {x, y, z, t} 或 None

  • batch_query(x_list, y_list) → List[Dict]
    批量查询多个点

  • query_by_range(z_min, z_max, t_min, t_max) → List[Dict] ⭐
    范围查询，返回满足条件的所有点

  • plot_3d(z_min=None, z_max=None, t_min=None, t_max=None, ...)
    三维可视化，可选择性地显示满足条件的点

  • plot_2d_heatmap(value_type='z', save_path=None)
    热力图可视化

  • get_grid_info() → Dict
    获取网格信息

================================================================================
                              使用示例
================================================================================

基本使用：

  from interpolation import Interpolator3D
  import numpy as np

  # 准备数据
  x = np.array([...])
  y = np.array([...])
  z = np.array([...])
  t = np.array([...])

  # 创建插值器
  interp = Interpolator3D(x, y, z, t)

  # 范围查询（核心功能）
  results = interp.query_by_range(0.2, 0.5, 8.0, 12.0)
  print(f"找到 {len(results)} 个点")

  # 可视化
  interp.plot_3d(z_min=0.2, z_max=0.5, t_min=8.0, t_max=12.0)

================================================================================
                              技术特点
================================================================================

1. 智能插值方法选择
   - 数据点 >= 10：使用 cubic 插值（三次样条）
   - 数据点 < 10：使用 linear 插值
   - 失败自动回退到 nearest 邻近插值

2. 高效的范围查询
   - 使用 NumPy 掩码操作
   - 时间复杂度：O(n)，n 为网格点数
   - 支持大规模数据集

3. 完善的错误处理
   - 数据验证
   - 范围检查
   - NaN 值过滤
   - 异常捕获和回退

4. 灵活的可视化
   - 三维曲面图
   - 条件点可视化
   - 二维热力图
   - 支持保存为图片
