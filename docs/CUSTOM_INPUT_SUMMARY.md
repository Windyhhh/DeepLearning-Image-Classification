## 📝 数据输入格式

```
x y z t
```

- **x**：第一个坐标（浮点数）
- **y**：第二个坐标（浮点数）
- **z**：第一个值（浮点数）
- **t**：第二个值（浮点数）

### 支持的数据类型
- ✓ 整数：`0 0 1 10`
- ✓ 小数：`0.5 0.5 1.5 15.5`
- ✓ 负数：`-1 -1 -5 -50`
- ✓ 混合：`0 1.5 10 20.5`
